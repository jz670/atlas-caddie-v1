ATLAS CADDIE — iPhone setup
1. Create a public repository at github.com (free account).
2. Upload index.html, manifest.json, sw.js and icon.png to its root.
3. Under Settings > Pages choose Deploy from a branch, main, / (root), Save.
4. Open the published HTTPS URL shown by Pages in iPhone Safari.
5. Share > Add to Home Screen > Add (enable Open as Web App if shown).
6. Launch online once, then verify offline access in airplane mode.
Your bag and courses are saved locally. Export backups in Courses. The standalone HTML can also be opened on a desktop for preview. Offline installation requires HTTPS. No GPS, live hazards or account sync. Elkhorn yardages are provisional; maximum distances are estimates. New courses start with placeholder hole distances which you edit in Planner.
